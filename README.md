# Dr. Khalid Khan Zadran — Neurosurgery Portfolio

Professional multilingual (EN / دری / پښتو) portfolio and appointment-request website for **Dr. Khalid Khan Zadran**, Consultant Neurosurgeon & Brain & Spine Specialist, Rifah Medical Complex, Kabul, Afghanistan.

## Tech Stack
- React 18 + Vite
- Tailwind CSS v4 (`@tailwindcss/vite`)
- Motion for React (`motion`)
- Lucide React icons
- React Router DOM v6
- Vitest + React Testing Library

## Install & Run
```bash
npm install
npm run dev       # development
npm run build     # production build
npm test          # run tests
